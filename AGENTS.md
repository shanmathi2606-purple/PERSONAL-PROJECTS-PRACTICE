# Repository Guidance

## Project Context
- This repository is a minimal personal-project practice workspace.
- `backend/app.js` currently contains a note describing an intended Express task-management API with GET and POST endpoints; it does not yet implement the API.
- No package manifest, lockfile, tests, or runtime-version file is currently present. Do not assume install, start, or test commands until those are added.

## Working In This Repository
- Inspect the relevant files and current worktree before making changes; `backend/` may contain untracked work.
- Keep changes focused on the requested task and preserve existing user-authored files.
- When adding backend behavior, first establish the project's dependency and execution setup, then add or update appropriate tests if a test framework is configured.
